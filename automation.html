PLC programming

Structured Text, state by state.

I program PLC logic in Structured Text (IEC 61131-3) on the Schneider platform. Machine sequences are easier to read, test and commission when they are written as clear state machines.

  • Structured Text on Schneider PLCs
  • Inverter parameter loading with SoMove
  • HMI with Vijeo Designer
Palletizer.st 
CASE State OF
  0:  (* Idle: wait for start and safety *)
      IF StartCmd AND SafetyOk THEN State := 10; END_IF

  10: (* Box on conveyor: request a pick *)
      IF BoxPresent THEN
          RobotPickReq := TRUE;
          State := 20;
      END_IF

  20: (* Robot cycle running *)
      IF RobotDone THEN
          RobotPickReq := FALSE;
          BoxCount := BoxCount + 1;
          State := 30;
      END_IF

  30: (* Layer complete? *)
      IF BoxCount >= BoxesPerPallet THEN
          PalletFull := TRUE;
          State := 0;
      ELSE
          State := 10;
      END_IF
END_CASE
